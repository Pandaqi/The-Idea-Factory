This is not really a game idea, just a very interesting way to do a **game board**: an octagonal grid!

* You have BIG tiles which are OCTAGONS (8-sided polygons)
* You have SMALL tiles which are DIAMONDS (4-sided, which slot perfectly into the gaps that the big tiles leave)

Now you can have a game with **two types of pawns**: 

* The "big ones" can only move over the octagons.
* The "small ones" can only move over those diamonds between the seams.

Additional idea: the goal is to race forward (toward some goal) ... and then race *backward* again through the mess you created! (First person back wins.)

Inspired by the look/grid of the game _Mariposas_.
