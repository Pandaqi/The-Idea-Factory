An incremental game, leaning towards more idle and more random.

The idea is simply that you **throw stuff and it bounces around the edges of the map**. Try to throw it in such a way that you hit as much as possible. If you capture "ammo" (or whatever) along the way, this allows you to **rethrow that thing** in a new direction.

Should work quite well.

The issue is ... that it's already been done to death.
