An incremental game fully focused on the prestige / rebirth aspect. 

You keep getting the option to kill your progress for some major permanent upgrade, then play again with that upgrade to get further faster (or be able to do stuff along the way that you weren't able to do before). This is the entire core of the game. Every time. There's no real upgrade tree; it's all in the rebirth loop.

For example, the **main part of the game** might be some randomly generated path from left to right, but that path is fixed/the same each time. 

* At first, you're like a tiny ant that can't get over most obstacles and can't interact with stuff. 
* As you reincarnate, though, you _can_ use more things from that path and pick different routes.
* You become bigger and bigger animals (/things?), faster and faster.
* Until you can finally complete the path.

I think this is a fascinating idea. I also think it's something I will never make because it requires massive patience in creating all that art, testing and balancing all the rebirths, creating that path in such a way that it works, etcetera. Beyond me right now.
