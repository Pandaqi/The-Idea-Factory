**A kind of block-based, small-scale, city builder as an incremental game.** 

So you get this specific landscape (different levels to solve, each one harder than the previous) with some rivers, hills, a target score, etcetera. 

Each run you get **random buildings to try and place**, trying to attract the right people / make them happy enough to continue. 

There is no deleting or rotating or anything. **Just clicking: here's the thing you need to place now, click an empty/valid cell.**

===> My issue with this is that it blurs the line between simply a strategy/building/puzzle game and an incremental game. We need to find a clear through line there and make it one thing specifically.
