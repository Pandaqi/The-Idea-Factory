## Tech Town / Skill State / Tech Throne

Other names: _Tech Throne_, _Throne of Tech_, _Skill State_. What's the idea?

> **An incremental game where the TECH TREE ==== YOUR KINGDOM.** 

In other words, each new thing placed must be the next evolution of the previous thing it attaches to. 

* Each "node" represents an upgrade in the tree, like "bronze archers"
* If you want to place something new, it has to connect to a previous node (like an upgrade/skill tree)
* And it will be an _upgrade_ to that previous node.
* So "bronze archers" -> "silver archers" next to it. (And then later, you connect -> "gold archers" to it.)

In this way, the upgrade tree becomes your actual kingdom/defense (it's _the same thing_).

This means upgrades can be re-bought all the time on purpose. It puts an interesting constraint by default on how you can build and what you can buy. 

This is actually quite a promising simplification of the entire genre---surely it has been done before? I guess the only issue is that it moves the game away from "incremental" and more into "tower defense/management".
