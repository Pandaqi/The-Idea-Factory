Something about _stealing_ or _breaking into a place_ or _finding treasure_. 

If everyone is on a different screen (online multiplayer), we can **limit their view and their "intel"**. Make it a bit dark or the building a bit bigger. 

* This would just be about avoiding cameras / shutting them off
* Throwing distractions to lead guards somewhere, which can just as easily lead them right into the path of an opponent player of course.
* Finding the right keys (copying/buying/trading/stealing if need be) for certain doors.

Then it would be **"competitive burglary"** where you all try to _not_ get caught while getting the biggest loot before time runs out. But because you're all in the same building, you influence each other all the time (such as leading guards directly to ANOTHER player) _and_ need to be the first in a room to get its loot.

_Examples/Inspiratins = "Monaco", "We Are So Cooked" (new game coming out somewhere)_
