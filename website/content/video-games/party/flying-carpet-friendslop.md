Basically, **FLYING CARPET: THE GAME**.

* You're all controlling one corner/side of a flying carpet.
* The game randomly generates some city to fly through.
* There's stuff on the carpet that's not allowed to fall/roll off.
* **Move from start to destination, losing as few packages as possible + not damaging the carpet too much!**

A really fun take on a friendslop / couch coop / silly party game about delivering packages. 

Should be able to easily randomly generate levels + city + goals too. 

Can be first-person view (even when not playing alone), because you're _all_ on the same flying carpet anyway. 

The carpet itself can be quite massive, though, to support those packages + make sure none fall through or create physics issues.

This is such a simple idea that really doesn't need anything more. Should be fast to make too, if you already have online multiplayer server/infrastructure in place.
